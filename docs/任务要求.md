==================================================
七、当前车辆真实 RX 协议
==================================================

原同济 GimbalToVision 是：

"SP"
+
43 byte
+
q[4] = Quaternion wxyz

当前车辆不是这个协议。

当前车辆 RX 为：

frame header：

0x5A

packed struct total：

44 bytes


实际字段布局：

offset 0
uint8_t head = 0x5A

offset 1
uint8_t mode

offset 2
uint8_t shoot_mode

offset 3
float q[4]

但注意：

q[0] = roll，单位 rad

q[1]
q[2]
q[3]

当前姿态重建中不使用，
不要解释成 quaternion xyz。

之后：

float yaw
float yaw_vel

float pitch
float pitch_vel

float bullet_speed

uint16_t bullet_count

uint8_t nuc_off

uint16_t crc16


因此 RX struct 应满足：

sizeof(GimbalToVision) == 44

必须使用 packed。

建议：

static_assert(sizeof(GimbalToVision) == 44);


==================================================
八、姿态语义
==================================================

当前下位机实际发送：

roll  = rx_data.q[0]
pitch = rx_data.pitch
yaw   = rx_data.yaw

单位：

rad


实车已经验证：

物理坐标：

+X = 发射机构向前
+Y = 从车后看向左
+Z = 向上

实测：

云台向左：
yaw 增大

枪口向上：
pitch 减小

与 X前 / Y左 / Z上的右手坐标系旋转约定一致。


==================================================
九、RPY → Quaternion
==================================================

原同济代码不能再：

Eigen::Quaterniond q(
    rx_data_.q[0],
    rx_data_.q[1],
    rx_data_.q[2],
    rx_data_.q[3]);

因为当前 q[4] 已经不再承载 Quaternion。


收到一帧合法 RX 后，应改成：

Eigen::Quaterniond q =
    Eigen::AngleAxisd(
        rx_data_.yaw,
        Eigen::Vector3d::UnitZ()) *
    Eigen::AngleAxisd(
        rx_data_.pitch,
        Eigen::Vector3d::UnitY()) *
    Eigen::AngleAxisd(
        rx_data_.q[0],
        Eigen::Vector3d::UnitX());

即：

R =
Rz(yaw)
*
Ry(pitch)
*
Rx(roll)

然后：

queue_.push({q, timestamp});

这样上层仍然只看到：

Eigen::Quaterniond

不要让 RPY 语义扩散到 Recorder 或其他上层模块。


==================================================
十、RX 找帧方式
==================================================

原同济如果仍然在：

先读取 2 byte

检查：

'S'
'P'

需要改掉。


当前协议应该：

逐字节寻找：

0x5A

逻辑类似：

uint8_t b;

read(&b, 1);

if (b != 0x5A)
    continue;

rx_data_.head = 0x5A;

记录当前接收时间 t；

然后读取：

sizeof(rx_data_)
-
sizeof(rx_data_.head)

剩余数据。

再检查整帧 CRC。
