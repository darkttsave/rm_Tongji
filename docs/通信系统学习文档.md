SP Vision 25 是一个**机器人视觉自瞄系统**,采用多种通信协议与硬件设备交互,实现实时的目标识别、姿态解算、轨迹规划和云台控制。

### 关键技术点

#### 1. 四元数插值 (SLERP)
```cpp
Eigen::Quaterniond CBoard::imu_at(time_point timestamp) {
  // 找到timestamp前后的两个数据点
  while (data_behind_.timestamp < timestamp) {
    data_ahead_ = data_behind_;
    queue_.pop(data_behind_);
  }
  
  // 计算插值系数
  double k = (timestamp - t_ahead) / (t_behind - t_ahead);
  
  // 球面线性插值
  Eigen::Quaterniond q = q_ahead.slerp(k, q_behind).normalized();
  return q;
}
```

**为什么需要插值?**
- 相机曝光时间戳与CAN数据接收时间不同步
- 通过插值获得相机曝光瞬间的精确姿态
- SLERP保证四元数在单位球面上平滑过渡

#### 2. 线程安全队列
```cpp
tools::ThreadSafeQueue<IMUData> queue_(5000);  // 容量5000

// 接收线程: CAN回调函数
void CBoard::callback(const can_frame& frame) {
  if (frame.can_id == quaternion_canid_) {
    // 解析四元数
    Eigen::Quaterniond q(w, x, y, z);
    queue_.push({q, timestamp});  // 线程安全入队
  }
}

// 主线程: 查询姿态
Eigen::Quaterniond q = cboard.imu_at(camera_timestamp);
```

#### 3. 自动重连机制
```cpp

void Gimbal::read_thread() {
  while (!quit_) {
    // 读取2字节帧头
    if (!read(&rx_data_.head, 2)) continue;
    
    // 验证帧头
    if (rx_data_.head[0] != 'S' || rx_data_.head[1] != 'P') 
      continue;  // 丢弃非法数据,继续寻找帧头
    
    // 读取剩余数据
    read(&rx_data_.mode, sizeof(rx_data_) - 2);
    
    // CRC校验
    if (tools::check_crc16(&rx_data_, sizeof(rx_data_))) {
      // 数据有效,处理...
    }
  }
}
```

```cpp
void Gimbal::reconnect() {
  for (int i = 0; i < 10 && !quit_; ++i) {
    tools::logger()->warn("Reconnecting... {}/10", i + 1);
    try {
      serial_.close();
      sleep(1s);
      serial_.open();
      queue_.clear();  // 清空旧数据
      tools::logger()->info("Reconnected successfully.");

    }
  }
}
```

### 数据格式

IMU数据分为**3个独立的帧**,每帧都有自己的CRC校验:

#### 帧1: 加速度数据 (16字节 + CRC)
```cpp
struct {
  uint8_t FrameHeader1 = 0x55;
  uint8_t flag1 = 0xAA;
  uint8_t slave_id1 = 0x01;
  uint8_t reg_acc = 0x01;
  uint32_t accx_u32;  // float转uint32
  uint32_t accy_u32;
  uint32_t accz_u32;
  uint16_t crc1;
  uint8_t FrameEnd1;
};
```

#### 帧2: 角速度数据 (16字节 + CRC)
```cpp
struct {
  uint8_t FrameHeader2 = 0x55;
  uint8_t flag2 = 0xAA;
  uint8_t slave_id2 = 0x01;
  uint8_t reg_gyro;
  uint32_t gyrox_u32;
  uint32_t gyroy_u32;
  uint32_t gyroz_u32;
  uint16_t crc2;
  uint8_t FrameEnd2;
};
```

#### 帧3: 欧拉角数据 (16字节 + CRC)
```cpp
struct {
  uint8_t FrameHeader3 = 0x55;
  uint8_t flag3 = 0xAA;
  uint8_t slave_id3 = 0x01;
  uint8_t reg_euler;
  uint32_t roll_u32;   // 单位: 度
  uint32_t pitch_u32;
  uint32_t yaw_u32;
  uint16_t crc3;
  uint8_t FrameEnd3;
};
```

### 数据解析流程

```cpp
void DM_IMU::get_imu_data_thread() {
  while (!stop_thread_) {
    // 1. 读取帧头(4字节)
    serial_.read(&receive_data.FrameHeader1, 4);
    
    // 2. 验证帧头
    if (receive_data.FrameHeader1 == 0x55 && 
        receive_data.flag1 == 0xAA &&
        receive_data.slave_id1 == 0x01 &&
        receive_data.reg_acc == 0x01) {
      
      // 3. 读取剩余数据(57-4=53字节,包含3帧)
      serial_.read(&receive_data.accx_u32, 53);
      
      // 4. 分别校验每一帧
      if (check_crc(&FrameHeader1, 16) == crc1) {
        // 解析加速度: uint32转float
        data.accx = *((float*)(&accx_u32));
        data.accy = *((float*)(&accy_u32));
        data.accz = *((float*)(&accz_u32));
      }
      
      if (check_crc(&FrameHeader2, 16) == crc2) {
        // 解析角速度
        data.gyrox = *((float*)(&gyrox_u32));
        data.gyroy = *((float*)(&gyroy_u32));
        data.gyroz = *((float*)(&gyroz_u32));
      }
      
      if (check_crc(&FrameHeader3, 16) == crc3) {
        // 解析欧拉角
        data.roll = *((float*)(&roll_u32));
        data.pitch = *((float*)(&pitch_u32));
        data.yaw = *((float*)(&yaw_u32));
        
        // 5. 欧拉角转四元数
        Eigen::Quaterniond q = 
          Eigen::AngleAxisd(yaw * M_PI/180, Vector3d::UnitZ()) *
          Eigen::AngleAxisd(pitch * M_PI/180, Vector3d::UnitY()) *
          Eigen::AngleAxisd(roll * M_PI/180, Vector3d::UnitX());
        
        // 6. 入队
        queue_.push({q, timestamp});
      }
    }
  }
}
```

### 欧拉角转四元数

**旋转顺序**: ZYX (Yaw → Pitch → Roll)

```cpp
// ZYX欧拉角转四元数
Eigen::Quaterniond euler_to_quat(float yaw_deg, float pitch_deg, float roll_deg) {
  double yaw = yaw_deg * M_PI / 180.0;
  double pitch = pitch_deg * M_PI / 180.0;
  double roll = roll_deg * M_PI / 180.0;
  
  return Eigen::AngleAxisd(yaw, Eigen::Vector3d::UnitZ()) *
         Eigen::AngleAxisd(pitch, Eigen::Vector3d::UnitY()) *
         Eigen::AngleAxisd(roll, Eigen::Vector3d::UnitX());
}
```

## 核心设计模式

### 1. 线程安全队列

**用途**: 解决生产者-消费者问题,实现线程间数据传递。

```cpp
template<typename T>
class ThreadSafeQueue {
  std::queue<T> queue_;
  std::mutex mutex_;
  std::condition_variable cv_;
  size_t max_size_;
  
public:
  // 阻塞式入队
  void push(T item) {
    std::unique_lock<std::mutex> lock(mutex_);
    cv_.wait(lock, [this] { return queue_.size() < max_size_; });
    queue_.push(std::move(item));
    cv_.notify_one();
  }
  
  // 阻塞式出队
  T pop() {
    std::unique_lock<std::mutex> lock(mutex_);
    cv_.wait(lock, [this] { return !queue_.empty(); });
    T item = std::move(queue_.front());
    queue_.pop();
    cv_.notify_one();
    return item;
  }
};
```

**应用场景**:
- CAN接收线程 → 主算法线程
- 串口接收线程 → 主算法线程
- IMU数据接收 → 姿态查询

### 2. 时间戳同步与插值

**问题**: 相机曝光时间与IMU数据接收时间不同步

**解决方案**: 维护带时间戳的数据队列,通过插值查询任意时刻的姿态

```cpp
struct IMUData {
  Eigen::Quaterniond q;
  std::chrono::steady_clock::time_point timestamp;
};

Eigen::Quaterniond imu_at(time_point t_query) {
  // 找到t_query前后的两个数据点
  IMUData before, after;
  find_surrounding_data(t_query, before, after);
  
  // 计算插值系数
  double k = (t_query - before.timestamp) / 
             (after.timestamp - before.timestamp);
  
  // 四元数球面线性插值(SLERP)
  return before.q.slerp(k, after.q).normalized();
}
```

**SLERP vs LERP**:
- LERP: 线性插值,会导致四元数偏离单位球面
- SLERP: 球面插值,保证结果仍在单位球面上,角速度恒定

```
     before.q
        ●
       /│\
      / │ \    SLERP沿大圆弧插值
     /  │  \
    /   ●   \  result (k=0.5)
   /    │    \
  /     │     \
 ●──────┼──────● after.q
        │
    单位球面
```

### 3. 自动重连机制

**设计思路**: 守护线程 + 状态标志

```cpp
class SocketCAN {
  std::atomic<bool> ok_;     // 连接状态
  std::atomic<bool> quit_;   // 退出标志
  
  std::thread read_thread_;   // 接收线程
  std::thread daemon_thread_; // 守护线程
  
  SocketCAN() {
    try_open();  // 初次打开
    
    // 守护线程: 监控连接状态
    daemon_thread_ = std::thread([this] {
      while (!quit_) {
        sleep(100ms);
        if (!ok_) {  // 检测到断开
          if (read_thread_.joinable()) 
            read_thread_.join();
          close();
          try_open();  // 尝试重连
        }
      }
    });
  }
  
  void read_thread_func() {
    ok_ = true;
    while (!quit_) {
      try {

  }
```

### 5. 数据校验

#### CRC16校验
```cpp
uint16_t get_crc16(const uint8_t* data, size_t len) {
  uint16_t crc = 0xFFFF;
  for (size_t i = 0; i < len; i++) {
    crc ^= data[i];
    for (int j = 0; j < 8; j++) {
      if (crc & 0x0001)
        crc = (crc >> 1) ^ 0xA001;
      else
        crc = crc >> 1;
    }
  }
  return crc;
}

bool check_crc16(const uint8_t* data, size_t len) {
  uint16_t calculated = get_crc16(data, len - 2);
  uint16_t received = *(uint16_t*)(data + len - 2);
  return calculated == received;
}
```

```cpp
bool is_valid_quaternion(const Eigen::Quaterniond& q) {

                   q.y()*q.y() + q.z()*q.z();
```
