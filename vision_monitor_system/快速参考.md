## 💻 最简C++集成代码
```cpp
// 1. 文件开头
#include "tools/plotter.hpp"
#include <nlohmann/json.hpp>

// 2. main函数中初始化
tools::Plotter monitor("127.0.0.1", 9870);

// 3. 主循环中（3行核心代码）
nlohmann::json data;
data["yaw"] = command.yaw; data["pitch"] = command.pitch;
data["target_x"] = ekf_state(0); data["target_y"] = ekf_state(1);
monitor.plot(data);
```

## ⚡ 性能优化技巧

### 降低发送频率
```cpp
static int counter = 0;
if (++counter % 3 == 0) {  // 每3帧发送一次
    monitor.plot(data);
}
```

### 减少字段数量
```cpp
// 调试时只发送关键字段
data["yaw"] = command.yaw;
data["target_x"] = ekf_state(0);
// 其他字段按需添加
```
