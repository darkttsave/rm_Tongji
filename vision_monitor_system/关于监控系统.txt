📁 这个文件夹包含完整的视觉监控系统

🚀 快速开始（3步）：

  第一步 - 安装依赖：
    cd vision_monitor_system
    ./install_monitor.sh

  第二步 - 测试系统：
    ./start_monitor_test.sh
    （会同时启动监控界面和测试数据）

  第三步 - 集成到C++代码：
    参考 monitor_integration_example.cpp
    在你的代码中添加3行代码即可

📊 监控功能：

  ✓ 云台Yaw/Pitch角度实时曲线
  ✓ 目标3D位置轨迹
  ✓ 目标速度和角速度
  ✓ 装甲板信息
  ✓ 射击状态
  ✓ 实时FPS和统计信息

📖 详细文档：

  中文文档：监控系统使用指南.md  （推荐先看）
  英文文档：MONITOR_README.md
  快速参考：README.md

💡 核心文件：

  vision_monitor.py              - 主监控程序
  test_data_sender.py            - 测试数据发送器
  monitor_integration_example.cpp - C++集成示例

🔧 使用方法：

  1. 在一个终端启动监控：
     python3 vision_monitor.py

  2. 在另一个终端运行你的C++程序：
     cd ../sp_vision_25-main/build
     ./standard  （或你的其他程序）

  3. 观察监控界面的实时数据
