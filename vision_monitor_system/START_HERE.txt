🎯 这是什么？
═══════════════════════════════════════════════════════════════════════════════

  这是一个为你的 sp_vision_25 项目开发的实时监控系统。
  
  它可以在你的C++代码运行时，通过可视化界面实时显示：
  
    ✓ 云台角度变化曲线
    ✓ 目标3D运动轨迹  
    ✓ 目标速度和角速度
    ✓ 射击状态
    ✓ 所有关键数据
  
  帮助你更好地调试和优化自瞄算法。

💻 集成到你的C++代码（只需3步）
═══════════════════════════════════════════════════════════════════════════════

  步骤1 - 在你的C++文件开头添加：
  
    #include "tools/plotter.hpp"
    #include <nlohmann/json.hpp>
  
  
  步骤2 - 在main函数中初始化：
  
    tools::Plotter monitor("127.0.0.1", 9870);
  
  
  步骤3 - 在主循环中发送数据：
  
    nlohmann::json data;
    data["yaw"] = command.yaw;
    data["pitch"] = command.pitch;
    data["target_x"] = ekf_state(0);
    data["target_y"] = ekf_state(1);
    data["target_z"] = ekf_state(2);
    monitor.plot(data);
  
  
  就这么简单！详细说明看：monitor_integration_example.cpp

❓ 常见问题
═══════════════════════════════════════════════════════════════════════════════

  Q: 监控窗口没有数据？
  A: 检查 C++ 程序是否在运行，是否调用了 monitor.plot(data)
  
  Q: 怎么改监听端口？
  A: 修改 monitor_config.json，或在代码中直接改
  
  Q: EKF状态向量索引不确定？
  A: 先打印整个向量，在监控界面观察对应关系
  
  Q: 图表更新卡顿？
  A: 降低发送频率，每3-5帧发送一次即可
  
  更多问题查看：监控系统使用指南.md 的"常见问题"部分


✅ 快速检查清单
═══════════════════════════════════════════════════════════════════════════════

  在集成前确认：
    □ Python 3 已安装
    □ numpy 和 matplotlib 已安装
    □ 运行 ./start_monitor_test.sh 测试通过
    □ 阅读了 monitor_integration_example.cpp
  
  集成时确认：
    □ 代码中包含了 plotter.hpp
    □ 创建了 Plotter 对象
    □ 在主循环中调用了 plot(data)
    □ 数据字段名称拼写正确
  
  运行时确认：
    □ 监控程序已启动
    □ C++ 程序正在运行
    □ IP:端口配置正确 (127.0.0.1:9870)
    □ 防火墙未阻止 UDP 通信


💡 技巧和建议
═══════════════════════════════════════════════════════════════════════════════

  调试技巧：
    • 先用测试数据验证监控系统工作正常
    • 逐步添加数据字段，不要一次性全加
    • 在C++代码中同时打印和发送数据，便于对比
    • 使用快速参考.md 作为速查手册
  
  性能优化：
    • 不要每帧都发送，每3-5帧发送一次即可
    • 只发送需要监控的关键字段
    • 减少历史数据长度可以提升流畅度
  
  集成位置：
    • 步兵：src/standard.cpp
    • 哨兵：src/sentry.cpp  
    • 调试：src/mt_auto_aim_debug.cpp
