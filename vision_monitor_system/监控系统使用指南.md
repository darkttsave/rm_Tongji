## 🚀 三步快速开始

### 第一步：安装依赖

在Ubuntu 22.04系统上运行：

```bash
cd /d/sp_vision_25-main
./install_monitor.sh
```

如果你在Windows上通过Git Bash运行，依赖需要手动安装：

```bash
pip3 install numpy matplotlib
```

### 第二步：测试监控程序

在**终端1**中启动监控程序：

```bash
python3 vision_monitor.py
```

在**终端2**中发送测试数据：

```bash
python3 test_data_sender.py --scenario normal
```

或者使用快速测试脚本（会同时启动两个程序）：

```bash
./start_monitor_test.sh
```

此时你应该看到：
- 监控窗口显示实时曲线图
- 状态面板显示实时数据
- 终端显示数据包统计信息

### 第三步：集成到你的C++代码

参考 `monitor_integration_example.cpp`，在你的代码中添加：

```cpp
#include "tools/plotter.hpp"
#include <nlohmann/json.hpp>

// 在main函数初始化
tools::Plotter monitor("127.0.0.1", 9870);

// 在主循环中发送数据
nlohmann::json data;
data["yaw"] = command.yaw;
data["pitch"] = command.pitch;
data["target_x"] = target_pos_x;
// ... 添加你需要的字段
monitor.plot(data);
```

## 📊 监控数据说明

### 你需要从代码中提取的数据

根据你的项目分析，以下是关键数据：

#### 1. 机器人状态（来自 `io::Command`）
```cpp
data["yaw"] = command.yaw;           // 云台yaw角度
data["pitch"] = command.pitch;       // 云台pitch角度
data["shoot"] = command.shoot;       // 是否开火
data["control"] = command.control;   // 控制是否激活
```

#### 2. 目标状态（来自 `auto_aim::Target`）
```cpp
auto ekf_state = target.ekf_x();

// 位置（根据你的EKF状态向量定义调整索引）
data["target_x"] = ekf_state(0);
data["target_y"] = ekf_state(1);
data["target_z"] = ekf_state(2);

// 速度
data["target_vx"] = ekf_state(3);
data["target_vy"] = ekf_state(4);
data["target_vz"] = ekf_state(5);

// Yaw信息
data["target_yaw"] = ekf_state(6);
data["target_yaw_velocity"] = ekf_state(7);

// 装甲板信息
data["armor_type"] = ARMOR_TYPES[static_cast<int>(target.armor_type)];
data["armor_name"] = ARMOR_NAMES[static_cast<int>(target.name)];
```

#### 3. 距离计算
```cpp
double distance = std::sqrt(
    ekf_state(0) * ekf_state(0) +
    ekf_state(1) * ekf_state(1) +
    ekf_state(2) * ekf_state(2)
);
data["distance"] = distance;
```

## 🔍 常见应用场景

### 场景1：调试云台跟踪

**目标：** 检查云台是否能准确跟踪目标

**观察图表：**
- 云台Yaw曲线
- 目标Yaw角度曲线

**判断标准：**
- 两条曲线应该基本重合
- 如果云台滞后，考虑调整PID参数
- 如果抖动明显，检查控制器稳定性

### 场景2：验证预测算法

**目标：** 确认目标运动预测是否准确

**观察图表：**
- 目标3D位置轨迹（应该是平滑的）
- 目标Yaw速度（应该稳定在一个值附近）

**判断标准：**
- 小陀螺时，轨迹应为圆形
- Yaw速度应与实际转速匹配
- 如果轨迹抖动，检查EKF参数

### 场景3：分析射击时机

**目标：** 优化开火决策逻辑

**需要添加的数据：**
```cpp
// 在你的决策器中
data["aim_error"] = tracking_error;        // 瞄准误差
data["predicted_yaw"] = predicted_yaw;     // 预测位置
data["shoot_decision"] = should_shoot;     // 开火决策
```

**观察：**
- 状态面板的射击指令状态
- 对比瞄准误差和射击决策的关系

### 场景4：性能优化

**需要添加的数据：**
```cpp
data["detect_time"] = detect_time_ms;      // 检测耗时
data["track_time"] = track_time_ms;        // 跟踪耗时
data["total_time"] = total_time_ms;        // 总耗时
data["fps"] = current_fps;                 // 帧率
```

**观察：**
- FPS显示（状态面板）
- 找出耗时最多的模块

## 🛠️ 实际集成步骤

### 步骤1：找到主循环

在你的项目中找到自瞄主循环，例如：
- `src/standard.cpp`
- `src/sentry.cpp`
- `src/mt_auto_aim_debug.cpp`

### 步骤2：添加Plotter

在文件开头添加：
```cpp
#include "tools/plotter.hpp"
#include <nlohmann/json.hpp>
```

在main函数中创建：
```cpp
tools::Plotter monitor_plotter("127.0.0.1", 9870);
```

### 步骤3：在合适位置发送数据

建议在以下位置发送：
1. **获取目标后** - 发送目标状态
2. **生成指令后** - 发送云台指令
3. **每帧结束时** - 发送完整状态

示例：
```cpp
while (running) {
    // 获取图像
    auto frame = camera.get_frame();
    
    // 检测装甲板
    auto armors = detector.detect(frame);
    
    // 跟踪目标
    tracker.update(armors, timestamp);
    auto targets = tracker.get_targets();
    
    // 生成指令
    auto command = aimer.aim(targets, timestamp, bullet_speed);
    
    // === 发送监控数据 ===
    if (!targets.empty()) {
        nlohmann::json data;
        const auto& target = targets.front();
        auto ekf_state = target.ekf_x();
        
        // 填充数据
        data["yaw"] = command.yaw;
        data["pitch"] = command.pitch;
        data["shoot"] = command.shoot;
        data["target_x"] = ekf_state(0);
        data["target_y"] = ekf_state(1);
        data["target_z"] = ekf_state(2);
        // ... 更多字段
        
        monitor_plotter.plot(data);
    }
    
    // 发送指令到下位机
    gimbal.send_command(command);
}
```

1. 先添加基本字段（yaw, pitch）
2. 验证数据正常后添加目标位置
3. 最后添加速度、加速度等

如果监控程序收不到数据：


## ❓ 常见问题

### Q: EKF状态向量索引不确定怎么办？

**A:** 查看 `tasks/auto_aim/target.cpp` 中的状态向量定义，或者先打印整个向量：

```cpp
auto ekf_state = target.ekf_x();
for (int i = 0; i < ekf_state.size(); ++i) {
    data["ekf_state_" + std::to_string(i)] = ekf_state(i);
}
```

然后在监控程序中观察哪些索引对应什么含义。

### Q: 图表更新不流畅怎么办？

**A:** 
1. 降低发送频率（不要每帧都发送）
2. 减少历史数据长度
3. 减少监控字段数量

```cpp
// 每隔几帧发送一次
static int frame_counter = 0;
if (++frame_counter % 3 == 0) {  // 每3帧发送一次
    monitor_plotter.plot(data);
}
```

### Q: 如何监控多个目标？

**A:** 为每个目标添加索引：

```cpp
int target_id = 0;
for (const auto& target : targets) {
    nlohmann::json data;
    data["target_id"] = target_id++;
    data["target_x_" + std::to_string(target_id)] = ...;
    // ...
    monitor_plotter.plot(data);
}
```

### Q: 可以同时运行多个监控程序吗？

**A:** 可以，使用不同的端口：

```cpp
// C++端
tools::Plotter monitor1("127.0.0.1", 9870);  // 自瞄监控
tools::Plotter monitor2("127.0.0.1", 9871);  // 性能监控
```

```bash
# Python端
python3 vision_monitor.py  # 默认9870
# 修改代码使用9871端口并再次运行
```
