# 数据包验证工具使用说明

## 功能介绍

这是一个带图形界面的数据包验证工具,用于验证上位机接收到的下位机数据包格式是否正确。

**主要功能:**
- ✅ 串口通信模式 - 连接真实硬件设备
- ✅ 模拟模式 - 无需硬件即可测试
- ✅ 实时数据包解析和显示
- ✅ CRC8/CRC16校验
- ✅ 数据包字段一一对应验证
- ✅ 统计信息显示(总数、有效、无效、成功率)
- ✅ 日志记录功能

## 安装依赖

```bash
pip install PyQt5 pyserial
```

## 运行程序

```bash
cd D:\sp_vision_25-main\sp_vision_25-main\tools
python packet_validator_main.py
```

## 使用步骤

### 1. 串口模式
1. 选择"串口模式"单选按钮
2. 从下拉列表中选择串口
3. 选择波特率(默认115200)
4. 点击"启动"按钮
5. 查看数据解析结果

### 2. 模拟模式
1. 选择"模拟模式"单选按钮
2. 设置发送间隔(1-10秒)
3. 点击"启动"按钮
4. 工具将自动生成符合协议的模拟数据包

## 自定义数据包协议

如需修改数据包格式,请编辑 `packet_validator_main.py` 中的 `create_default_protocol()` 方法:

```python
def create_default_protocol(self):
    protocol = PacketProtocol("自定义协议名称")
    
    # 添加字段: 字段名, 字节数, 类型, 描述
    protocol.add_field(PacketField("帧头", 1, "uint8", "起始标志"))
    protocol.add_field(PacketField("数据", 2, "uint16", "数据内容"))
    # ... 添加更多字段
    
    return protocol
```

**支持的字段类型:**
- `uint8` - 无符号8位整数
- `uint16` - 无符号16位整数(小端序)
- `uint32` - 无符号32位整数(小端序)
- `float` - 32位浮点数(小端序)
- `double` - 64位浮点数(小端序)

## 验证逻辑

工具会自动验证以下内容:

1. **帧头检查** - 验证帧头是否为0xA5
2. **CRC8校验** - 如果协议包含CRC8字段,自动验证包头CRC
3. **CRC16校验** - 如果协议包含CRC16字段,自动验证整包CRC
4. **数据包长度** - 验证接收到的数据长度是否符合协议定义

## 注意事项

1. 工具会自动查找帧头(0xA5)来同步数据包
2. CRC校验算法与C++代码中的实现保持一致
3. 所有多字节数据使用小端序(Little-Endian)
4. 模拟模式生成的数据包自动包含正确的CRC校验值

## 故障排除

**问题: 提示"未安装pyserial"**
- 解决: 运行 `pip install pyserial`

**问题: 找不到串口设备**
- 检查设备是否正确连接
- 检查驱动程序是否安装
- 点击"刷新"按钮重新扫描串口

**问题: CRC校验总是失败**
- 确认下位机的CRC算法与本工具一致
- 检查数据字节序(大端/小端)是否匹配
- 使用模拟模式验证工具本身是否正常
